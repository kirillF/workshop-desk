# Investigate your assigned focus

Derive expectations from sources and challenge relevant boundaries with concrete
scenarios. Record observed paths/probes using the supplied check schema:

- suspected: evidence suggests a reachable failure needing verification.
- refuted: a guard or contract rules out this scenario, only within the scope checked.
- unresolved: evidence or intent is missing; specify the gap in openQuestion.
- not_checked: a relevant check was blocked or unfinished; explain why.

Keep independent counterexamples separate. Retain concrete hypotheses before final
publication filtering; no priorities, fix plans or quotas. If none are suspected,
return meaningful checks and unverified areas. Use a tracked location or null.

Keep fields concise: expectation, source, trigger and observed evidence each once,
without repeating explanations. Preserve counterevidence and specific limits.
A refuted scenario does not establish a feature-wide guarantee. Record material
unexamined cases as not_checked rather than extending a negative conclusion to them.
This session has no access to the other investigation's conclusions. Reserve time
to return the check records.
